# Impedimento Milimetrico 4.0

Simulador SAOT + ICC para a Copa do Mundo FIFA 2026.

## Arquitetura

- **Modulo SAOT**: Engine de impedimento 3D com calculo milimetrico.
- **Modulo ICC**: Centro de comando com gemeos digitais e assistente IA.
- **Shared**: Componentes reutilizaveis, DataOverlay, Error Boundaries.

### Tecnologias

- React 18 + TypeScript (strict)
- Zustand (estado)
- @react-three/fiber + drei (3D)
- Recharts (graficos)
- Tailwind CSS v4

### Como rodar

```bash
npm install
npm run dev
```

Acesse http://localhost:5173 e utilize as abas SAOT Lab e ICC Command Center.
